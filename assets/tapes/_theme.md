# The recording theme

justwrite paints its own chrome in truecolor, so the terminal theme only decides
two things: the colour of the page behind the text, and the default foreground.
Both are pinned in every tape rather than inherited, so a capture made on any
machine comes out identical.

```
background  #0D0D0B   near-black, a shade warm, so the amber sits on it naturally
foreground  #E6E2D6   the same ink the editor uses for the writing
```

The sixteen ANSI slots are filled with an amber-leaning set for completeness.
Nothing in justwrite reaches for them — it addresses colours directly — but VHS
wants a full palette and a half-filled one would leave the rest to chance.

Keep the block identical across tapes. If it changes, every capture has to be
regenerated together or the set stops looking like one product.
